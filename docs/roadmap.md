# ULOHA Release Roadmap

ULOHA is being released in stages. This repository is the entry point for the paper, project website, videos, and future releases.

## Current scope

- Project overview and demonstration media.
- Links to the paper, project website, and videos.
- Citation metadata and release status.


## Preparing for release

- Hardware design files.
- ULOHA software, based on a modified and extended version of LeRobot, and usage documentation.

The final release scope and repository locations are being determined. Links will be added to the [main README](../README.md) as materials become available.
